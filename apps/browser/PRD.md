# 跨境电商防关联浏览器 核心产品需求文档 (PRD) v2.0

基于对头部竞品（AdsPower、Dolphin{anty}、Hubstudio、GoLogin 等）的行业深度分析，结合跨境电商（Amazon/Shopee铺货坑位）、海外社媒营销（Facebook/TikTok矩阵）以及网赚（Affiliate）的真实业务痛点，制定本软件的完整功能需求表。

---

## 1. 核心竞品特性对标与产品定位

| 产品 | 核心优势 | 主要受众 | 自动化能力 | 浏览器内核 |
| :--- | :--- | :--- | :--- | :--- |
| **AdsPower** | 强大的内置 RPA 自动化、极高的团队权限细分、商业化极其成熟 | 跨境团队、大卖工作室，追求高并发 | 原生 No-Code RPA 工作流，支持常规 API | Chromium + Firefox |
| **Dolphin{anty}**| 界面极其清爽丝滑、内核指纹对抗更新快、非常适合社媒养号 | 独立站投手、社媒自动化、个人网客 | 脚本流程构建器，提供本地接口调取 | 仅 Chromium |
| **我们的定位** | **超低内存开销 (Tauri)、更深层的 C++ 级指纹伪装、专攻极限防封** | Amazon/FB 精品矩阵、对代理封禁极度敏感的进阶用户 | 提供 Local API 对接 Puppeteer/Selenium，内置基础养号脚本 | 深度魔改 Chromium |

## 2. 完整功能需求矩阵表 (Feature Matrix)

### 模块一：环境与核心指纹管控 (Fingerprint Manager)
这是立足之本，确保不同 Profile（浏览器环境）在平台探针中被认作现实世界中物理隔离的真实个人电脑。

| 功能模块 | 需求详细描述 | 优先级 |
| :--- | :--- | :--- |
| **操作系统欺骗** | 支持伪装成 Windows、macOS、Linux、Android、iOS 环境布局。 | P0 |
| **核心指纹置换** | Canvas 指纹、WebGL 图像及元数据指纹、AudioContext 音频指纹的固定噪点注入。 | P0 |
| **硬件特征伪装** | 屏幕分辨率与可用区域尺寸（基于 OS 特征限制）、CPU 核心数、设备内存 (Device Memory) 伪造。 | P0 |
| **基础特征伪造** | User-Agent 随机与平台绑定、Accept-Language 伪装、ClientRects 偏差补偿。 | P0 |
| **字库与媒体隔离** | 基于伪造 OS 提供限定的系统字库名单；隔离 MediaDevices (摄像头/麦克风枚举)。 | P1 |
| **UserData 物理隔离**| 为每个环境创建相互绝对物理隔绝的 `Profile/Cache/IndexedDB/Localstorage` 目录。 | P0 |

### 模块二：代理网络与地理合规 (Proxy & Geo-Location)
代理不仅是为了翻墙，更是为了让 IP、时区、经纬度完美对应，骗过严苛的异地登录检测。

| 功能模块 | 需求详细描述 | 优先级 |
| :--- | :--- | :--- |
| **多协议支持** | 支持 HTTP / HTTPS / SOCKS5 / SSH 等主流代理协议接入。 | P0 |
| **平台代理集成** | API 对接常见动态/静态住宅代理商 (如 Oxylabs, Luminati, 911s5 等)，实现面板内直接提取 IP。 | P2 |
| **自动时区与语系** | **[自动修正]**：填入代理 IP 后，服务端自动解析 IP 归属地，并将浏览器时区、语言强制变更为当地标准。 | P0 |
| **WebRTC 强效防漏**| 基于代理协议，强制将 WebRTC 公网 IP 替换为代理 IP，彻底阻断本地内网局域网 IP (`192.168.x.x`) 的侧漏渗透。 | P0 |
| **地理位置 (LBS) 定位**| 篡改 HTML5 GeoLocation API，定位经纬度自动匹配至代理 IP 所在城市的随机坐标上。 | P1 |

### 模块三：账户运营与团队协作 (Operations & Team)
针对拥有十几个员工、上百个店铺/广告账户的主管需求。

| 功能模块 | 需求详细描述 | 优先级 |
| :--- | :--- | :--- |
| **Cookie 批量导入/出** | 支持基于 JSON / Netscape 格式的一键批量导入 Cookie，实现免密直接登录（买卖账号常用）。 | P0 |
| **密码免明文共享** | 管理员分配环境给打工人，打工人打开即可登录 Amazon/FB，但**无法提取或看到真实的明文密码**，离职随时收回权限。 | P1 |
| **角色与权限分配** | 主账户、经理、普通员工。精细化配置员工：能否创建环境、能否导出 Cookie、能否删除配置。 | P1 |
| **跨设备云同步** | 员工在家或在公司登录客户端，自动拉取加密的环境配置，所有书签、缓存、甚至开启的 Tab 页云端同步恢复。 | P2 |
| **环境批量转移** | 支持勾选多个环境批量“转移所有权”或“共享”给外部协作者用户（外包养号常用）。 | P1 |

### 模块四：扩展中心与自动化 (Automation & RPA)
高级网客每天需要让几百个号自动“浏览网页、点赞、加购”来养持权重。

| 功能模块 | 需求详细描述 | 优先级 |
| :--- | :--- | :--- |
| **浏览器插件统管** | 面板里包含一个插件应用中心。一键给 100 个环境同时预装指定的 Chrome 扩展（如 MetaMask、Amazon 抓取插件）。 | P1 |
| **Local API 对接** | 外壳客户端在规定端口开启本地 REST / WebSocket 接口。允许外部使用 Python (Selenium / Puppeteer / Playwright) 直接唤起并控制指定序号的浏览器。 | P1 |
| **可视化内置 RPA (远期)** | 内置免代码的拖拽式流程构建器（点击某按钮、输入某文本、等待几秒）。员工可自己画流程图，让 50 个号同时执行自动化养号。 | P3 |
| **群控同步 (Synchronizer)**| 打开一个“主浏览器”，后续新开的“从浏览器”跟随主浏览器的鼠标点击、键盘输入，实现 1 控 10（适合批量撸空投）。 | P2 |

## 3. 执行路线图与 MVP 规划

| 开发期限 | 里程碑 (Milestones) | 验收标准 |
| :--- | :--- | :--- |
| **MVP (Phase 1)** | **底层免疫内核与基础管理** | 魔改编译完成的 Chromium 引擎，跑过 CreepJS、Ipleak 等严苛检测。单机版 Tauri 外壳能配置简单的 HTTP 代理并唤起浏览器。 |
| **V1.0 (Phase 2)** | **团队云端与账号矩阵运营** | 跑通主子账号注册、代理平台批量导入、Cookie的加密双向云同步、员工权限分配验证。提供基础 Local API 操作。 |
| **V2.0 (Phase 3)** | **商业化与高级工作流** | 加入 SaaS 订阅计费墙（套餐限额）；上线可视化 RPA 面板；插件中心批量分发。 |
