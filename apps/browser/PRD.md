# 跨境电商防关联浏览器产品需求文档 (PRD)

## 1. 产品背景与目标
针对跨境电商卖家（Amazon、Shopee）、独立站运营、海外社媒投放（Facebook、TikTok）团队由于“一机多登”导致账号被平台判定关联而遭到封锁的痛点，打造一款高度定制的防关联浏览器环境。
目标是实现“账号-硬件指纹-IP环境”的彻底隔离，为每个店铺或账号生成唯一的、稳定的原生硬件环境指纹。

## 2. 目标用户与使用场景
- **跨境卖家**：管理多店铺、多品牌运作，隔离Cookie池与店铺行为。
- **投放团队**：管理大量广告账户，防止单一账户违规导致整个商务管家（BM）关联封号。
- **工作室/网赚**：矩阵刷量、批量自动化交互。

## 3. 核心功能设计

### 3.1 环境管控（核心）
- **独立环境模型**：每个环境对应一套唯一的硬件级浏览器指纹组合（OS、UserAgent、分辨率、时区、语言、Canvas、WebGL、Audio 指纹）。
- **指纹固化**：环境一经创建，其硬件指纹特征长期绑定，无论是在哪台物理电脑上打开，目标网站读取到的硬件参数必须丝毫不差。
- **数据物理隔离**：每个环境独立一个 UserData 目录（Cache、Cookie、IndexedDB 完全隔离）。

### 3.2 代理网络模型
- 支持 HTTP(S) / SOCKS5 / SSH 路由代理引入。
- 支持基于 IP 地理位置自动识别并匹配对应国家的**时区**、**语言配置**，防止出现“美国 IP 但是中国时区”的风控特征。
- WebRTC 本地真实 IP 泄露防护。

### 3.3 团队协作与权限分配
- 主子账号机制。
- **无密码协同**：管理者可在团队内部直接分享浏览器环境，操作员打开即可继承 Cookie 登录状态，但无法查看到明文密码。
- 设备转移与云端双向同步。

## 4. 阶段规划
- **Phase 1: 内核魔改实现（第一期重中之重）** —— 跑通 Chromium 编译流程，实现 C++ 级别防御，能在 CreepJS 等严苛测试下不暴露本地真实特征。
- **Phase 2: 客户端系统实现** —— 开发本地管理终端，实现环境增删改查、代理测试。
- **Phase 3: 云端管理中心** —— 实现订阅计费、数据同步传输。
