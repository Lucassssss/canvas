## 重要说明

### 关于 tldraw 的使用限制

**⚠️ 授权协议限制**：tldraw 的许可证不允许在生产环境中免费使用。因此，我们不能直接使用 tldraw 库。

### 实现策略

**参考而非引用**：我们将参考 tldraw 的架构设计和实现思路，但会完全自研一个新的画布库。具体策略如下：

1. **架构参考**：参考 tldraw 的编辑器架构、状态管理、工具系统等设计模式
2. **代码自研**：所有代码重新实现，不直接引用 tldraw 的任何代码
3. **功能裁剪**：仅实现 PRD 中梳理的产品需求，不实现 tldraw 的全部功能
4. **独立运行**：新应用完全独立，不依赖现有任何应用

### 参考资源

- **tldraw 库**（仅参考架构）：`/lib/tldraw`
- **Agent 实现参考**（仅参考设计模式）：`/apps/canvas`

### 技术栈要求

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端框架 | Vite + React 19 + TypeScript | 不依赖 Next.js |
| 后端服务 | Bun + Express | 参考 `/apps/api` 的实现方式 |
| AI SDK | Vercel AI SDK | 不使用 LangChain |
| 状态管理 | Zustand | 轻量级状态管理 |
| 样式 | Tailwind CSS | 原子化 CSS |

### 部署目标

- **前端**：导出为静态独立 HTML，可独立部署
- **后端**：Express API 服务，独立运行
- **独立应用**：`apps/ai_draw`，后续将移除其他应用

## 1. 产品愿景

### 1.1 核心愿景

**构建一个基于无限画布的 AI 驱动设计平台，让用户能够像操作真实画布一样自由创作，同时享受 AI 带来的智能化设计辅助。**

### 1.2 产品定位

| 维度 | 描述 |
|------|------|
| **产品类型** | AI 驱动的无限画布设计工具 |
| **核心差异化** | 纯 DOM 实现 + AI Agent 深度集成 + 试衣功能 |
| **部署方式** | 本地部署（前后端分离） |
| **LLM 基础** | DeepSeek / OpenAI / MiniMax |

## 2. 核心功能模块

### 2.1 画布引擎（Canvas Core）

#### 2.1.1 技术实现
- **渲染方式**：纯 DOM 实现，不使用 Canvas 或 SVG
- **定位系统**：CSS `transform: matrix()` 实现精确定位
- **坐标系统**：绝对坐标系统，支持无限范围
- **图层管理**：z-index 控制元素层级

### 2.3 AI Agent 系统

#### 2.3.1 架构设计
```
User Input → Build Prompt → LLM Streaming → Parse Actions → Execute → Update Canvas
```

#### 2.3.2 Agent 能力
| 能力 | 描述 |
|------|------|
| 创建元素 | 在画布上创建各种形状 |
| 更新元素 | 修改元素属性（位置、大小、颜色等） |
| 删除元素 | 删除指定元素 |
| 批量操作 | 对齐、分布、排序等 |
| 思考输出 | 显示 Agent 的思考过程 |
| 任务管理 | 维护 Todo 列表 |
| 视口控制 | 移动视口查看不同区域 |

#### 2.3.3 Prompt Parts（Agent 输入）
| Part 类型 | 描述 |
|-----------|------|
| User Message | 用户输入的消息 |
| Viewport | 当前视口信息（中心点、缩放级别） |
| Shapes | 画布上的元素信息 |
| Selected Shapes | 当前选中的元素 |
| History | 操作历史 |
| Chat History | 对话历史 |

#### 2.3.4 Agent Actions（Agent 输出）
| Action 类型 | 描述 |
|-------------|------|
| create | 创建元素 |
| update | 更新元素 |
| delete | 删除元素 |
| move | 移动元素 |
| resize | 调整大小 |
| rotate | 旋转元素 |
| align | 对齐元素 |
| distribute | 分布元素 |
| bringToFront | 置顶 |
| sendToBack | 置底 |
| message | 发送消息给用户 |
| setViewport | 设置视口 |
