## 1. 项目概述

### 1.1 项目背景

由于 tldraw 的授权协议限制（不允许在生产环境免费使用），我们需要自研一个无限画布设计平台。项目参考 tldraw 的架构设计，但完全独立实现代码。半小时后我们将使用此应用给投资人展示，请

### 1.2 核心目标

构建一个基于无限画布的 AI 驱动设计平台，支持：

- 纯 DOM 实现的无限画布
- AI Agent 深度集成
- 试衣功能（核心特色）
- 图片/视频生成

### 1.3 技术约束

| 约束项           | 说明                    |
| ------------- | --------------------- |
| 不使用 tldraw    | 仅参考架构，代码完全自研          |
| 不使用 LangChain | AI 功能使用 Vercel AI SDK |
| 不依赖现有应用       | `apps/ai_draw` 完全独立   |
| 前后端分离         | 前端静态 HTML，后端 Express  |

## 6. 关键设计决策

### 6.1 画布引擎（已确认）

- **渲染方式**：纯 DOM，不使用 Canvas/SVG
- **定位系统**：CSS `transform: matrix()`
- **坐标系统**：绝对坐标，无限范围
- **图层管理**：z-index

### 6.2 UI 设计（已确认）

- **设计风格**：Lovart 风格，简洁现代
- **组件库**：shadcn/ui + Tailwind CSS
- **图标库**：Lucide React
- **参考实现**：`/apps/web`

### 6.3 AI 集成（已确认）

- **AI SDK**：Vercel AI SDK
- **不使用**：LangChain
- **模型**：DeepSeek / OpenAI / MiniMax

### 6.4 部署方式（已确认）

- **前端**：静态 HTML，可独立部署
- **后端**：Express 服务，独立运行
- **独立应用**：不依赖现有应用

## 7. 风险与注意事项

### 7.1 技术风险

| 风险      | 影响        | 缓解措施       |
| ------- | --------- | ---------- |
| DOM 性能  | 大量元素时可能卡顿 | 虚拟滚动、元素懒加载 |
| 浏览器兼容   | 不同浏览器表现差异 | 充分测试，渐进增强  |
| AI 响应延迟 | 用户体验差     | 流式响应、加载状态  |

### 7.2 实现注意事项

1. **不复制 tldraw 代码**：仅参考架构设计思路
2. **保持独立**：`apps/ai_draw` 不依赖其他应用
3. **代码规范**：使用 TypeScript 严格模式
4. **性能优先**：画布操作保持 60fps
