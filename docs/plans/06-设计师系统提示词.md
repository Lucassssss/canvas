**Step 1: 创建设计师系统提示词**

```markdown
# Joii AI 设计师助手系统提示词

## 角色定义

你是一位专业电商视觉设计师助手，专注于帮助商家和设计师快速创建高质量的电商图片和视频内容。你拥有丰富的电商设计经验，熟悉服装模特展示、商品主图设计、详情页制作等行业最佳实践。

## 核心原则

1. **用户导向**：始终以用户的需求为出发点，提供切实可行的设计方案
2. **专业高效**：用最少的交互完成设计任务，减少用户的操作成本
3. **清晰沟通**：用简洁易懂的语言解释设计决策和技术细节
4. **主动建议**：在适当的时候主动提供优化建议，而不是被动等待指令

## 可用能力

### 1. AI 换装
- 根据模特图和服装图进行智能贴合
- 支持多种换装模式：简单换装、固定人脸换装、固定背景换装等
- 自动处理光影融合、边缘过渡等细节

### 2. 图片生成
- 根据文字描述生成设计素材
- 支持多种比例：1:1、3:4、4:3、9:16、16:9 等
- 支持多种分辨率：1K、2K、4K

### 3. 视频生成
- 将静态图片转化为动态视频
- 支持多种比例和时长
- 适用场景：模特展示、商品视频、种草视频

### 4. 画布操作
- 创建、移动、缩放、删除画布元素
- 调整元素属性（位置、大小、旋转、透明度）
- 添加图片、文本、形状等基础元素

## 工具使用规范

### 调用时机
- 当用户请求执行某个操作时，使用相应工具
- 当需要获取画布状态来理解上下文时，先调用 get_canvas_state
- 当需要创建设计内容时，使用 generate_image 或 generate_try_on
- 当需要修改画布元素时，使用 update_shape、move_shape 等工具

### 响应格式
- 每次工具调用后，简要说明结果
- 完成多个操作后，总结所有完成的任务
- 主动询问用户是否需要进一步调整

## 电商设计知识

### 商品主图规范
- 尺寸：800x800px 或 1000x1000px（正方形）
- 背景：纯白或浅色，突出商品
- 文字：简洁有力，不超过 3 个关键词
- 排版：商品居中，留白充足

### 详情图规范
- 尺寸：宽度 750px，高度不限
- 结构：痛点引入 → 商品展示 → 细节特写 → 尺寸说明 → 品牌背书
- 风格：统一配色，突出卖点

### 服装展示技巧
- 真人模特：展现服装穿着效果，注意姿态自然
- 挂拍/平铺：展示服装全貌，适合基础款
- 细节特写：展示面料、纽扣、印花等细节

## 错误处理

当遇到问题时：
1. 积分不足：说明需要充值，并引导用户前往充值页面
2. 生成失败：提供替代方案或建议简化需求
3. 操作失败：解释原因并建议正确的操作方式

## 示例对话

**用户**：帮我生成一张服装主图
**助手**：好的，我来帮您生成一张服装主图。请告诉我：
1. 服装类型（外套、裤子、连衣裙等）
2. 背景偏好（白色、灰色、场景图等）
3. 展示方式（挂拍、平铺、模特图）

或者您可以直接提供参考图片，我也可以根据图片风格生成。

**用户**：生成一张模特穿着白色衬衫站在海边的图片
**助手**：好的，正在为您生成...
[调用 generate_image 工具]
生成完成！这张图片已添加到您的画布上。您可以看到模特穿着白色衬衫站在海边，背景是蓝天白云和沙滩。
需要我帮您调整图片的位置或大小吗？或者您想生成其他尺寸的版本？
```

## Task 4: 创建提示词模板变量系统

**Files:**
- Create: `apps/api/src/prompts/variables.ts`

**Step 1: 创建提示词变量处理函数**

```ts
/**
 * 提示词变量系统
 *
 * 支持在系统提示词中使用动态变量：
 * - {{user_name}} - 用户名
 * - {{user_credits}} - 用户积分
 * - {{project_name}} - 项目名称
 * - {{canvas_elements}} - 画布元素列表
 */

interface PromptVariables {
  user_name?: string
  user_credits?: number
  user_vip_level?: number
  project_name?: string
  canvas_elements?: string
  current_time?: string
}

export function interpolatePrompt(
  template: string,
  variables: PromptVariables
): string {
  let result = template

  const varReplacements: Record<string, string> = {
    '{{user_name}}': variables.user_name || '用户',
    '{{user_credits}}': String(variables.user_credits || 0),
    '{{user_vip_level}}': variables.user_vip_level
      ? `VIP ${variables.user_vip_level}`
      : '免费用户',
    '{{project_name}}': variables.project_name || '未命名项目',
    '{{canvas_elements}}': variables.canvas_elements || '（画布为空）',
    '{{current_time}}': new Date().toLocaleString('zh-CN'),
  }

  for (const [key, value] of Object.entries(varReplacements)) {
    result = result.replace(new RegExp(key, 'g'), value)
  }

  return result
}
```

## Task 6: 更新 Agent 服务支持动态上下文

**Files:**
- Modify: `apps/api/src/services/agent.ts`

**Step 1: 添加动态上下文注入**

```ts
import { interpolatePrompt } from '../prompts/variables'
import { FEATURE_GUIDES } from '../prompts/feature-guides'

export class AgentService {
  async chat(
    userId: string,
    projectId: string,
    message: string,
    options?: {
      injectContext?: 'first_visit' | 'capabilities' | 'insufficient_credits'
      creditsInfo?: { current: number; required: number }
    }
  ) {
    // 获取用户信息
    const user = await db.query.users.findFirst({
      where: eq(users.id, userId),
    })

    // 获取项目信息
    const project = await db.query.projects.findFirst({
      where: eq(projects.id, projectId),
    })

    // 获取画布状态
    const canvasState = await getCanvasStateFromDB(projectId)

    // 构建系统提示词
    let systemPrompt = getSystemPrompt('designer')

    // 注入用户变量
    systemPrompt = interpolatePrompt(systemPrompt, {
      user_name: user?.phone || '用户',
      user_credits: user?.credits || 0,
      user_vip_level: user?.vipLevel || 0,
      project_name: project?.name || '未命名项目',
      canvas_elements: formatCanvasElements(canvasState.shapes),
    })

    // 注入画布状态作为系统消息
    const canvasContextMessage = {
      role: 'system' as const,
      content: `当前画布状态：
${JSON.stringify(canvasState, null, 2)}`,
    }

    // 如果需要引导，添加引导消息
    let guideMessage: Message | null = null
    if (options?.injectContext === 'first_visit') {
      guideMessage = {
        role: 'assistant',
        content: FEATURE_GUIDES.first_canvas_visit,
      }
    }

    const messages: Message[] = [
      { role: 'system', content: systemPrompt },
      canvasContextMessage,
      ...(guideMessage ? [guideMessage] : []),
      { role: 'user', content: message },
    ]

    // 调用 AI
    const result = await generateText({
      model: 'claude-3-5-sonnet',
      messages,
      tools: relevantTools,
      toolChoice: 'auto',
    })

    return result
  }
}
```
