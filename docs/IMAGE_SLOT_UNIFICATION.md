## 1. 功能概述

### 1.1 背景

当前系统中存在独立的图片组件和换装组件，但缺乏灵活的自定义组合能力。用户需要一种可视化的方式创建自己的图片处理流程。

### 1.2 目标

1. **全新图片槽位组件** - 创建新的 `ImageSlot` 组件类型
2. **可视化组合创建** - 通过点击+号动态添加输入槽位
3. **图片拖拽互通** - 任意图片可拖入其他组合的输入槽位
4. **常驻配置面板** - 组合下方始终显示配置选项

## 4. ImageSlot 组件设计

### 4.1 组件接口

```typescript
interface ImageSlotProps {
  // 基础属性
  id: string
  imageUrl?: string
  label?: string
  placeholder?: string
  
  // 尺寸
  width?: number              // 默认 140
  height?: number             // 默认 180
  
  // 交互能力
  draggable?: boolean         // 是否可被拖出，默认 true
  droppable?: boolean         // 是否可接收拖入，默认 true
  clickable?: boolean         // 是否可点击上传，默认 true
  exportable?: boolean        // 是否可导出，默认 true
  clearable?: boolean         // 是否可清除，默认 true
  deletable?: boolean         // 是否可删除（组合内），默认 false
  
  // 样式
  variant?: 'input' | 'output' | 'standalone'
  
  // 事件
  onImageChange?: (imageUrl: string, source: 'upload' | 'drop' | 'canvas') => void
  onImageClear?: () => void
  onDelete?: () => void
  onLabelChange?: (label: string) => void
}
```

### 4.2 组件状态

| 状态 | 样式 | 说明 |
|------|------|------|
| 空状态 | 灰色背景 + 上传图标 | 显示 placeholder |
| 加载中 | 灰色背景 + 加载动画 | 图片加载中 |
| 已有图片 | 显示图片 | 鼠标悬停显示操作按钮 |
| 拖入悬停 | 蓝色边框高亮 | 拖拽图片悬停时 |
| 加载失败 | 灰色背景 + 错误提示 | 图片加载失败 |

### 4.3 右键菜单

| 菜单项 | 条件 | 功能 |
|--------|------|------|
| 复制图片 | 有图片 | 复制图片URL到剪贴板 |
| 导出图片 | 有图片 + exportable | 下载图片文件 |
| 清除图片 | 有图片 + clearable | 清除当前图片 |
| 删除槽位 | deletable | 删除此槽位（组合内） |
| 重新上传 | clickable | 重新选择图片文件 |

## 5. CustomCombination 组件设计

### 5.1 组件接口

```typescript
interface CustomCombinationProps {
  id: string
  x: number
  y: number
  
  // 槽位配置
  inputSlots: Array<{
    id: string
    label: string
    imageUrl?: string
  }>
  outputSlots: Array<{
    id: string
    label: string
    imageUrl?: string
  }>
  
  // 生成配置
  config: {
    model: string
    resolution: { width: number; height: number }
    prompt: string
  }
  
  // 状态
  status: 'idle' | 'generating' | 'completed' | 'error'
  error?: string
}
```

### 5.2 组件布局

```
宽度：根据输入槽数量自动计算
高度：输入槽高度 + 间距 + 输出槽高度 + 配置面板高度

布局计算：
- 输入槽宽度: 140px
- 输入槽间距: 12px
- +号按钮: 32px
- 左右内边距: 24px

总宽度 = 24 + (140 × 输入槽数量) + (12 × (输入槽数量 - 1)) + 12 + 32 + 24
```

### 5.3 交互行为

| 交互 | 行为 |
|------|------|
| 点击 + 号 | 添加新的输入槽 |
| 悬停槽位 | 显示删除按钮（如果可删除） |
| 双击标签 | 进入编辑模式 |
| 拖入图片 | 设置该槽位的图片 |
| 拖出输出图片 | 可拖入其他组合的输入槽 |
| 点击执行 | 调用 AI 生成接口 |

## 6. 拖拽交互设计

### 6.1 拖拽数据结构

```typescript
interface ImageDragData {
  type: 'image-slot' | 'image' | 'combination-output'
  sourceId: string              // 来源组件ID
  sourceSlotId?: string         // 来源槽位ID
  imageUrl: string
}
```

### 6.2 拖拽场景

| 拖拽源 | 放置目标 | 行为 |
|--------|----------|------|
| 独立图片组件 | 自定义组合输入槽 | 设置输入槽图片 |
| 自定义组合输出 | 其他组合输入槽 | 设置输入槽图片 |
| 图片槽位 | 其他组合输入槽 | 设置输入槽图片 |

### 6.3 实现方式

使用原生 HTML5 Drag & Drop API：
- `draggable` 属性启用拖拽
- `onDragStart` 设置拖拽数据
- `onDragOver` / `onDrop` 处理放置

与组件移动互不干扰：
- 拖拽：长按后触发，用于图片流转
- 移动：mousedown + mousemove，用于组件位置调整

## 11. 风险与注意事项

1. **组件尺寸**：输入槽数量多时组件会变宽，需考虑画布边界
2. **拖拽冲突**：确保图片拖拽与组件移动互不干扰
3. **性能**：大量槽位时注意渲染性能
4. **跨域图片**：导出功能需处理跨域图片问题
5. **内容审核**：社区分享需要内容审核机制
6. **隐私保护**：用户创建的组件需考虑隐私设置
